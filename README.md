
# React Native Meal / Recipe App 🍲

A mobile recipe app built with React Native and Expo, where users can browse meals, view details, and select their favorite recipes.

The app demonstrates dynamic routing, state management, and a clean, responsive UI.


## Features

- Browse meals by category
- View detailed meal recipes
- Mark meals as favorite and filter favorites
- Dynamic routing for Meal Detail pages
- Built with React Native and Expo


## Tech Stack

React Native – For cross-platform mobile UI

Expo – Fast development and testing

React Navigation – For dynamic routing between screens

React Hooks – For state management

##🚀 Getting Started
##Prerequisites

Node.js installed

Expo CLI installed (npm install -g expo-cli)


## Run Locally

Clone the project

```bash
  git clone https://github.com/Benjilo12/React-native-MealsApp.git
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm  start
```
